Your first working session

  1. Prepare the working computer

    Install Node.js 22 or newer, tmux, and the terminal helper. Download Scheme and run its doctor. There is no application build or package-install step.

    Open the host setup guide

  2. Open a Shell

    Start Scheme, open the local dashboard, then choose ＋ New, Shell, and Start. The guide includes a harmless first command.

    On an 8 GiB host, use the documented 1 GiB memory reserve for the Shell test.

  3. Connect another screen

    Use an SSH tunnel from another desktop, or follow the private Tailscale guide for a desktop or phone. Keep Scheme bound to the host’s local address.

    Connect a desktop / Connect a phone

What we actually tested

Two hosted graphical Ubuntu 24.04 ARM64 desktops, each with 8 GiB of memory: host setup, a real Shell, viewing through SSH, browser closure and reconnection, a Scheme service restart, and host reboot recovery. The Shell test used the documented 1 GiB reserve.

Cloud AI and Tailscale sign-ins, physical phones, macOS hosting, and WSL hosting remain unverified. A reboot starts a new process; it does not preserve a running job.
