Tailscale · any device
set up tailscale serve on the host (see Connect)
SSH tunnel
ssh -L 3000:localhost:3000 user@host then open http://localhost:3000

The Connect tab explains both paths step by step.

Confirm

Scheme listens on this host's loopback address only. To use it from another computer or a phone you bring that loopback to yourself with an SSH tunnel (same network) or with Tailscale (anywhere). Both paths land on 127.0.0.1, which is what the terminal plane requires. The full guide is INSTALL-REMOTE.md in the repository.

On this host

Local browser

http://localhost:3000

Open this on the machine that runs Scheme. Everything works here without any tunnel.

Another computer · same network

SSH tunnel

Run this on the other computer, keep the window open, then open the local address it forwards.

ssh -L 3000:localhost:3000 user@host

then open http://localhost:3000 on that computer.

Windows one-click connector (.bat)

Needs an SSH key already accepted by this host. The connector opens the tunnel and your browser in one double-click.

Anywhere · phone included

Tailscale

Install Tailscale on this host and on the device you connect from, then run this once on the host:

tailscale serve --bg --https=443 http://127.0.0.1:3000

From then on Scheme is reachable on your private tailnet at:

not detected yet — install Tailscale on the host and run the command above

tailscale: not detected on the host

Never use tailscale funnel: that exposes the port to the public internet, and Scheme refuses to serve the terminal while it detects a Funnel.

Sanity check

Is the terminal unlocked?

The Terminal tab shows a lock card when your connection is not loopback. Over a tunnel or Tailscale it shows the session bar instead.

  1. Open the Terminal tab.
  2. Press ＋ New, pick a runtime, press Start.
  3. A session tab appears and the agent boots inside it. Close the browser — the session keeps running.
